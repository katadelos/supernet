# k2 integration

k2 provides optional graphical controls for Supernet in **Developer tools**.
Install both `supernet` and `k2` to use this interface. SSH key setup and
connection settings are described in the [Supernet README](../README.md#install-and-connect).

## Using the controls

Open **Developer tools** and choose USB, Wi-Fi or both to start SSH access.
Connect Wi-Fi through the reader's normal settings first. The page shows the
connection addresses and provides controls for stopping SSH, managing ADB and
keeping the reader awake when those capabilities are available.

Use the displayed Wi-Fi address when connecting from your computer. Stop access
before choosing another transport or changing connection settings. The controls
use the same commands and lifecycle as the command-line interface.

## Packaging

The [feature descriptor](../integration/k2/supernet.json) registers Supernet as a
`remote-access` feature titled **Developer tools** on Kindle and Kobo. It invokes
`/usr/bin/supernet` and declares a terminal icon for the popover.

Install the descriptor relative to the package staging root:

```sh
install -D -m 0644 integration/k2/supernet.json stage/usr/share/k2/features/supernet.json
```

The [integration guide](../integration/README.md#status-and-controls) describes
the JSON status fields and command interface used by the controls.
